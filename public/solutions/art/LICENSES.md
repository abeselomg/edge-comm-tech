# Solution hero art: licences and provenance

Every file in this folder is a composite built by us on 2026-10-26 from Microsoft Fluent UI Emoji "3D" PNG icons
(256x256 originals) placed on an isometric platform and soft cyan glow that we drew ourselves as plain SVG
shapes (not third-party art). The composition, platform, shadows and layout are ours; only the icons are third-party.

- Creator: Microsoft Corporation (Fluent UI Emoji project)
- Source repository: https://github.com/microsoft/fluentui-emoji
- File pattern: `https://raw.githubusercontent.com/microsoft/fluentui-emoji/main/assets/<Name>/3D/<name>_3d.png`
- Licence: MIT License, https://github.com/microsoft/fluentui-emoji/blob/main/LICENSE
- Attribution: the MIT licence requires the copyright and permission notice to be kept "in all copies or substantial portions of the Software".
  It is not a visible-credit licence; keeping this notice in the repository (and, to be safe, in a site licences/credits page or source comment) satisfies it.
  Suggested text: "3D icons: Copyright (c) Microsoft Corporation, MIT License, github.com/microsoft/fluentui-emoji".
- Retrieved: 2026-10-26
- Modifications for all files: icons rescaled (about 130-420 px), composited with drop shadows onto our own isometric platform SVG, trimmed to content, quantised PNG (palette) with alpha. No colour edits to the icons.
