# Edge COMM-TECH

Corporate site for Edge Communication Technologies. First slice: home, global chrome, and a public E-Academy (modules → lessons → video, no login).

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Academy seed: `/academy/iam-fundamentals`.

Payload CMS + Postgres is the next scaffold step (not in this first pass; `create-payload-app` could not run unattended against this empty folder).
